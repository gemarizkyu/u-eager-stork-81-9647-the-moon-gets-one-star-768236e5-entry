## The Moon Gets One Star

A one-star review of the Moon, 120 characters at most, written to be the funniest line in the field. `main.py` writes a single fixed review to `/output/entry.txt`:

> One star. Follows me home every night and just stares. 4.5 billion years, never blinked once. Would not recommend.

114 characters. A complaint about the Moon itself — the follow-you-home illusion only the Moon pulls off, plus its 4.5-billion-year age — in a real reviewer's voice, with no craters, no cheese, and no brightness joke.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt` (override the directory with `OUTPUT_DIR` for local testing). Deterministic: one fixed line, no wall clock, no randomness, no network, no model calls.
